# Brand assets

Source logo files. Not bundled into the app; the app icon and splash under `assets/images/` are generated from these.

| File                         | What                                                    | Use on                           |
| ---------------------------- | ------------------------------------------------------- | -------------------------------- |
| `mark-gold.webp`             | House + speech-bubble mark, gold `#D4AF37`, transparent | Ink / dark backgrounds, app icon |
| `mark-ink.webp`              | Same mark, ink `#1A1A1A`, transparent                   | Light backgrounds, monochrome    |
| `logo-horizontal-light.webp` | Mark + wordmark + tagline, ink text                     | White / light backgrounds        |
| `logo-horizontal-dark.webp`  | Mark + wordmark, white text                             | Ink / dark backgrounds           |

Wordmark: Inter Tight 700. Tagline: Inter 500. Colors per CLAUDE.md §4.
